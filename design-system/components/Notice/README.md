# Notice

A full-width band under the header for the one thing every reader must see before the numbers: sample data, a scope limit, a correction.

- `band` fill, 1px `line-strong` rule below, `body` text in `ink-2`; the first sentence is bold `ink`.
- One or two sentences. Use it at most once per report. Leave it out when there is nothing to disclose.
- Provide: the notice text with its first sentence marked strong.
