# StatTile

A row of three to five headline figures under the dek: a label, a value, and a mono delta against a named period.

- `card` fill, 1px `line` border, `radius-card`; `label` in `ink-3`, value in `stat`, delta in `meta` `ink-3` with ▲ or ▼.
- Deltas name the comparison ("vs last week"). Don't colour deltas: direction is in the arrow, judgement belongs in the prose.
- Only use tiles when the figures are the point of the report; otherwise put numbers in sentences.
- Provide: label (sentence case, no colon), value (compact: 1,284 / 12.9K / $4.2M), optional delta.
