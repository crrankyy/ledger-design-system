# Header

The strip across the top of a report: a name in `wordmark`, a short mono sub-line for the report type, and one mono meta item on the right.

- `surface` fill with a 1px `line` rule below; 14px by `space-6` padding (`space-4` on phones).
- Name: the publisher, team or report series, never a product logo you were not given. Sub-line: the report type ("Weekly report", "Audit"). Meta: the report id or date.
- Provide: name, sub-line, meta. Place it once, first on the page. The notice band, if any, sits directly under it.
